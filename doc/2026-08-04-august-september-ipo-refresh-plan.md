# 2026년 8월·9월 공모주 데이터 보강 계획

> 2026-08-09 재점검: 이 계획을 현재 KST 기준으로 다시 실행한다. 후보 원장은
> `monthly-ipo-audit-2026-08-09.json`으로 갱신하고, 8월 4일 이후 발표된
> 수요예측 결과와 일정 정정 사항을 동일한 검증 게이트로 반영한다.

## Idea Summary

2026년 8월 1일부터 9월 30일까지의 국내 일반 공모 청약 일정을 여러 최신 공개 출처로 전수 대조하고, 저장소에 빠진 종목·일정·공모 기본값과 단계별 결과 지표를 보완한다. 생성 JSON을 직접 수정하지 않고 정식 입력 파일을 갱신한 뒤 전체 피드를 재생성한다.

## MVP Scope

### Core user problem

앱 사용자가 8월·9월 청약 후보를 누락 없이 보고, 공개 단계가 지난 종목에서는 공모가·기관 경쟁률·의무보유확약·일반청약 결과 등 이미 발표된 값이 비어 있지 않아야 한다.

### Must-have flows

1. 세 개 이상의 독립 일정표와 공식 공시·주관사 자료에서 후보를 수집한다.
2. 회사명과 청약 시작·종료일로 기존 이벤트와 정확히 대조한다.
3. 공개 단계별 필수값을 정식 입력 파일에 채우고 미발표 값은 `null`로 유지한다.
4. 로컬 전용 배치로 종목 파일과 `active`, `upcoming`, `recent`, `yearly` 피드를 재생성한다.
5. 후보 원장 감사, 저장소 검증, Dart 분석, JSON 파싱과 diff 검사를 통과한다.

### Out of scope

- 유상증자, 스팩 합병, 이미 상장된 종목의 별도 증권 발행
- 공개되지 않은 수치의 추정 또는 0 대입
- 사용자 승인 없는 Git 커밋·원격 푸시

### Success criteria

- 2026년 8월·9월 후보 원장의 `unresolved`가 0건이다.
- 모든 대상 후보가 정확히 하나의 canonical ID와 종목 파일을 가진다.
- 월간 감사 `ERROR`가 0건이고 모든 변경 JSON이 파싱된다.
- 공개 단계가 지난 후보의 필수값 누락은 공개 지연 사유가 문서화된 경우만 남는다.

## Feature Specification

### 후보 일정 정합성

- 목적: 월별 청약 목록의 누락·중복·오인 매칭 방지
- 흐름: 일정표 발견 → 공식 근거 확인 → 회사명·청약일·시장·주관사 대조 → matched/added/excluded/unresolved 분류
- 상태 변경: `data/discovered/ipo_events.json`
- 오류 상태: 이름 충돌, 날짜 충돌, 공모 유형 불명확
- 수용 기준: 모든 후보에 근거 URL과 분류 사유가 있다.

### 공개 지표 보강

- 목적: 발표된 공모·수요예측·일반청약 값을 앱에 제공
- 흐름: 공개 단계 판정 → 공식 결과 확인 → 단위 정규화 → 수동 사실·브로커 스냅샷 반영
- 상태 변경: `data/manual_fundamentals.json`, 필요 시 `data/broker_snapshots/`
- 오류 상태: 수량/신청 기준 확약 혼동, 잠정치를 최종값으로 오인, 퍼센트 단위 오류
- 수용 기준: 미발표는 `null`, 발표값은 출처와 올바른 단위로 기록된다.

### 피드 재생성 및 검증

- 목적: 정식 입력 변경을 앱 소비 JSON에 일관되게 반영
- 흐름: 검토된 로컬 배치 → 월간 감사 → 검증 → 전체 diff 검토
- 상태 변경: `ipo_competition_data/`
- 오류 상태: 중복 ID, 끊어진 경로, 피드 누락, 무관한 점수·날짜 변경
- 수용 기준: 모든 오류가 0이고 변경 범위가 대상 월과 필요한 보고서로 제한된다.

## Wireframe

```text
[공개 일정 3개+] ─┐
[DART/주관사] ────┼─> [8·9월 후보 원장]
[기존 canonical] ─┘        │
                            ├─ matched / added
                            ├─ excluded + 사유
                            └─ unresolved = 0
                                   │
                     [정식 입력 파일 보강]
                                   │
                     [로컬 전용 배치 재생성]
                                   │
                 [월간 감사 + 분석 + JSON + diff]
                                   │
                       [검증된 로컬 결과물]
```
